# AI Data Cleaner

أداة سطر أوامر بلغة Python لتحليل وتنظيف ملفات CSV.

## المزايا المخططة

- قراءة ملفات CSV.
- فحص بنية البيانات والقيم الناقصة.
- إزالة الصفوف المكررة.
- إنشاء ملف بيانات نظيف.
- إنشاء تقرير بعمليات التنظيف.

## إعداد المشروع

```bash
python -m venv .venv
source .venv/Scripts/activate
python -m pip install -r requirements.txt
```

## حالة المشروع

المشروع قيد التطوير كجزء من التطبيق العملي لمراحل إعداد مهندس الذكاء الاصطناعي.
